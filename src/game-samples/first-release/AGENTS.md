# 작업 지침

## 범위와 승인

- 한국어로 설명한다. 식별자는 ASCII를 사용한다.
- 시작 전에 저장소·브랜치·기존 변경을 확인하고 사용자 변경을 보존한다.
- 이 폴더 안의 최초 릴리스만 작업한다. 상위 안내서와 다른 샘플은 수정하지 않는다.
- 이 작업은 사용자가 허용한 **문서와 샘플의 자동 산출물 리허설**이다. 단계별 참가자 승인, 실제 app 조작, 커밋을 했다고 기록하지 않는다.
- 일반 워크숍에서는 Plan의 읽기 전용 검토 뒤 승인한 작은 작업만 Interactive에서 수행한다. 이번 리허설의 일괄 실행 허용을 향후 작업의 포괄 승인으로 해석하지 않는다.
- 커밋은 상위 작업자가 검토한 뒤 처리한다. 푸시·PR·병합·공개 배포는 별도 승인 없이 하지 않는다.
- 최초 릴리스 종료 후 멈춘다. 일시정지 개선을 미리 구현하지 않는다.

## 기준과 검증

- `ideation.md` → `PRD.md` → `TRD.md` → `IMPLEMENTATION_PLAN.md` 순으로 읽는다. 제품 규칙은 PRD, 구현 방법은 TRD가 기준이며 충돌을 조용히 덮지 않는다.
- Node.js 24 LTS, ES modules, Canvas 2D, Vite, Node 내장 테스트, Playwright만 사용한다. 외부 게임 코드·에셋·Plugin을 복제하거나 실행하지 않는다.
- manifest 작성 뒤 최초 `npm install`로 잠금 파일을 만든다. 이후 재현 설치는 `npm ci`이다. Chromium은 Playwright 의존성 설치 후 준비한다.
- `npm test`는 `node --test tests/*.test.js`이며 `npm run test:e2e`, `npm run build`를 별도로 실행한다.
- E2E 서버는 `127.0.0.1:5173`을 직접 관리하며 기존 서버를 재사용하거나 모르는 프로세스를 종료하지 않는다.
- 결과는 `TEST_RESULTS.md`에 실제 증거만 남긴다. 실패를 삭제하거나 수용 기준을 낮추지 않는다. 미수행은 미확인이다.
- 비밀정보·개인 경로·생성된 의존성·빌드·보고서를 커밋하지 않는다. 커밋 요청이 있으면 한국어 제목·본문에 단계·이유·실제 결과·미확인을 기록한다.
- 이 문서는 Custom agent 정의가 아니다. 명시적 읽기와 app의 자동 지침 적용 검증을 구분한다.
