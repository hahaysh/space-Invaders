정확한 시간·좌표는 sleep 대신 순수 dt 또는 브라우저의 제어된 시계와 Canvas 픽셀을 사용한다.
브라우저가 승패를 강제로 주입하지 않는다. Node에서 공개 순수 상태를 구성하는 경계 검사는 실제 인간 플레이와 구분한다.

## 수동 한 판 절차

1. `npm run preview -- --host 127.0.0.1 --port 4173 --strictPort`로 자신의 서버만 실행한다.
2. 버튼과 Enter 시작을 새로고침하며 각각 확인한다. ←/→/A/D와 Space를 사용한다.
3. 모든 적을 직접 제거해 240점·승리 확인, 방향·Space가 종료 화면을 바꾸지 않는지 확인한다.
4. R로 재시작하고 발사 없이 기다려 패배 확인, 버튼 재시작으로 0점·24개를 확인한다.
5. 창 전환 뒤 키 붙음·점프가 없는지 확인하고 여러 판의 속도를 비교한다.
6. 관찰하지 못한 항목은 미확인으로 남긴다. 종료 시 자신이 시작한 서버만 종료한다.

공개 저장소 생성, app 세션·지침 UI 확인, Pages 설정·배포는 이번 자동 리허설 범위가 아니다.
