# 구현 계획

## 적용 방식

문서 → 구현 → 자동 검사 → 실패 수정·회귀 → 결과 기록 순으로 진행한다.
일반 워크숍은 작업마다 참가자 승인·커밋을 요구한다. 이번에는 사용자가 허용한
산출물 리허설 범위에서 이어서 실행하며 중간 인간 승인·검증·커밋을 꾸며내지 않는다.

| 작업 | REQ | 의존 | 변경 파일 | 완료 기준·검증 | 최초 상태 |
|---|---|---|---|---|---|
| M1 첫 조작 화면 | 01~03, 08 일부 | 문서 설계 | HTML, game/main/styles, 패키지·Vite·Playwright 설정 | title 시작, 이동 경계, 첫 발·간격, DOM; 관련 Node/E2E | 미착수 |
| M2 적·충돌 | 04~05 | M1 | game/main, 규칙 검사 | 24개, 경계 하강, 탄환 단일 명중·중복 점수 없음 | 미착수 |
| M3 종료·재시작 | 06~08 | M2 | game/main, 규칙·브라우저 검사 | 승패, 동결, 완전한 초기화, 회귀·빌드 | 미착수 |
| QA | 01~08 | M3 | TEST_PLAN, 테스트, TEST_RESULTS | `npm test`, `npm run test:e2e`, `npm run build` 실제 실행 | 미착수 |
| CI 예제 | 08 | QA | `.github/workflows/pages.yml` | guide 06-02와 경로·권한·의존성 대조, 원격 실행 제외 | 미착수 |

M1/M2/M3의 최종 코드를 한 샘플에 누적한다. 각 중간 버전별 실행 성공은 최종 검증으로 대신 주장하지 않는다.
작성 당시 상태는 위와 같으며 실제 진행·완료 증거는 아래에 나중에 기록한다.

## 실제 진행

2026-09-13 산출물 리허설을 완료했다. 아래의 완료는 **최종 코드·자동 검사 기준**이며
각 중간 버전의 참가자 확인이나 커밋 완료를 뜻하지 않는다.

| 작업 | 최종 상태 | 실제 근거 |
|---|---|---|
| M1 | 완료 | TC-01~03, TC-08의 순수·브라우저 검사, 제목·플레이 화면 캡처 |
| M2 | 완료 | TC-04/05 편대·충돌 검사, 브라우저 실제 발사·점수 |
| M3 | 완료 | TC-06/07, TC-12 자연 승패·재시작·동결·이동 속도 검사 |
| QA | 완료 | Node 35/35, Chromium 10/10, 빌드·하위 경로 검사 통과; TEST_RESULTS에 실패 이력 보존 |
| CI 예제 | 완료 | 06-02와 이벤트·권한·배포 의존성·dist 경로를 대조한 YAML 작성; 원격 실행은 미확인 |

구현 전 문서·계획을 작성한 뒤 game/main/스타일·설정, 규칙·브라우저 검사 순으로 만들었다.
M1~M3 중간 버전을 따로 저장하거나 실행하지 않고 완성본을 검증했다.
QA에서 접근성 상태 선택자 모호성을 수정하고 정상 키 조작 승리·패배 및 빌드 하위 경로 검사를 보강했다.
상위 작업자의 검토·최초 체크포인트 커밋을 기다린다. 개선 릴리스는 시작하지 않았다.
