# 궤도 수호대 — 최초 릴리스

한국어 워크숍의 문서 → 구현 → 검증 과정을 자동으로 리허설한 독립 실행 샘플이다.
실제 Copilot app UI, 새 GitHub 저장소 생성, 단계별 인간 승인·커밋, 원격 배포까지 수행한 결과가 아니다.
외부 게임 코드나 이미지 없이 직접 그린 도형으로 구성한다. 일시정지는 최초 버전에 없다.

## 실행

이 폴더를 작업 루트로 사용한다. Node.js 24 LTS가 필요하다.

```powershell
npm ci
npx playwright install chromium
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

`http://127.0.0.1:5173`에서 데스크톱 키보드로 조작한다.
Enter/버튼 시작, ←/→ 또는 A/D 이동, Space 유지 발사, 종료 후 R/버튼 재시작.
창을 벗어나면 키가 해제되지만 일시정지는 아니다.

## 검사·빌드

수동 개발 서버를 종료한 뒤 아래를 실행한다. 모르는 서버의 포트를 강제로 비우지 않는다.

```powershell
npm test
npm run test:e2e
npm run build
node scripts\check-build.mjs
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

E2E는 자체 `127.0.0.1:5173` 서버를 관리하고 종료한다. 빌드 결과는 `dist`뿐이다.
빌드 검사는 임의의 loopback 포트에서 `/first-release/` 하위 경로의 실제 JS/CSS 로드와 시작을 검증하고 종료한다.
Playwright 생성 보고서·스크린샷은 `test-results`에 남으며 Git 추적에서 제외된다.

## 문서와 리허설 순서

| 안내 단계 | 산출물·확인 |
|---|---|
| REFERENCES, 00 | 범위·출처 확인, 원본 코드·에셋·Plugin 실행 제외 |
| 01-02/03 | 문서 책임 분리, `AGENTS.md` 작성·명시적 읽기 |
| 02-01~03 | `ideation.md` → `PRD.md` → `TRD.md`를 코드보다 먼저 작성 |
| 03-01/02 | 수치·상태·설계·검증 연결 대조, 자동 리허설 승인 범위 명시 |
| 04-01 | `IMPLEMENTATION_PLAN.md`에 M1~M3·검증 의존성 작성 |
| 04-02/03 | 시작·이동·발사 → 적·충돌 → 종료·재시작의 최종 코드 작성 |
| 05-01/02 | 테스트 계획 선작성, 실제 검사와 결함 수정·회귀 결과 기록 |
| 06-02 | 독립 샘플 루트 기준 Pages 워크플로 작성, 실제 배포 제외 |

테스트 계획은 구현 전에 작성해 검증 조건을 고정했다. 안내서의 05단계 문서 작성 시점보다 앞당긴 리허설 차이다.
중간 단계마다 별도 플레이·커밋을 했다고 주장하지 않는다. 자세한 실제 증거와 미확인은 [TEST_RESULTS.md](TEST_RESULTS.md)를 본다.

## 배포 예제와 제한

`.github/workflows/pages.yml`은 **이 폴더 내용이 독립 저장소 루트에 있을 때** 사용할 예제다.
현재 상위 안내 저장소에서는 중첩 워크플로가 활성화되지 않는다.
PR은 검사만 하고 main push/main 수동 실행은 검사 성공 뒤 `dist`를 Pages로 배포한다.
실제 Pages Source·환경·권한·공개 URL은 별도 승인과 확인이 필요하다.
`base: './'`로 저장소 하위 경로의 에셋을 지원한다.

## 발견한 안내·환경 차이

- 00의 “샘플은 현재 없음”은 이 산출물을 만들기 전 상태 설명이다. 상위 문서 수정은 상위 작업자 담당이다.
- `npm view vite version`의 latest가 사전 배포판을 가리켰다. 그대로 설치하지 않고 안정 버전을 별도로 선택한다.
- 참가자별 승인·커밋·실제 app 조작은 자동 산출물 리허설로 검증할 수 없다.
