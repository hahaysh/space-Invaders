# 제품 요구사항 — 최초 릴리스

## 목표와 좌표

800×600 논리 화면에서 한 편대를 막는 데스크톱 키보드 게임이다.
좌상단이 (0, 0), 오른쪽·아래쪽이 양수다. 위치는 도형의 좌상단, 속도는 픽셀/초다.
화면은 비율을 유지해 축소되지만 터치 조작은 제공하지 않는다.

## 확정 수치

| 대상 | 규칙 |
|---|---|
| 플레이어 | 40×20, 시작 (380, 550), 이동 320, x 범위 [0, 760] |
| 탄환 | 4×12, 플레이어 가로 중앙·바로 위에서 생성, 위로 600 |
| 발사 | Space 유지 시 첫 발 즉시, 이후 최소 0.2초 간격; 해제 후에도 남은 대기시간 유지 |
| 편대 | 3행×8열, 적 40×24, 첫 적 (112, 72), 열 간격 72·행 간격 48 (좌상단 간 거리) |
| 적 이동 | 오른쪽으로 시작, 64; 살아 있는 적의 양 끝이 x=0 또는 x=800에 도달하면 반전·24 하강 |
| 경계 | 편대는 경계에 정확히 맞추고 남은 이동시간을 반전 방향에 적용; 한 도달당 하강 한 번 |
| 점수·방어선 | 적당 10, 최대 240; 살아 있는 적 하단 y≥520이면 패배 |
| 시간 | 한 프레임 최대 0.1초만 진행, 최대 1/240초 세부 갱신 |

## 필수 요구사항

| ID | 우선순위 | 정상·경계·금지 수용 기준 |
|---|---|---|
| REQ-01 | 필수 | 초기 `title`, 0점. Enter 또는 시작 버튼만 `playing`으로 시작. 시작 전 이동·발사 없음. 제목 화면에서 R 무시. |
| REQ-02 | 필수 | `playing`에서만 ←/→ 또는 A/D 이동. y=550 고정, x는 0~760. 좌·우 모두 눌리면 정지. 같은 방향의 여러 키 중 하나를 놓아도 다른 키가 눌렸으면 계속 이동. |
| REQ-03 | 필수 | `playing`에서만 Space 유지 발사. 즉시 첫 발, 0.2초 미만에는 다음 발 없음, 도달하면 가능. 탄환 하단≤0이면 제거. 제목·종료에서 눌린 키를 다음 판으로 넘기지 않는다. |
| REQ-04 | 필수 | 초기 24개. 살아 있는 적의 경계로 수평 이동·반전·한 번 하강. 죽은 적은 편대 경계를 결정하지 않는다. |
| REQ-05 | 필수 | AABB 사각형의 양의 면적 겹침만 충돌. 접촉만 있으면 비충돌. 탄환 하나는 최대 적 하나 제거 후 소모, 죽은 적 중복 득점 없음, 점수 최대 240. |
| REQ-06 | 필수 | 각 세부 갱신에서 이동→충돌→종료 판정. 살아 있는 적 하단≥520이면 `lost`, 그렇지 않고 적이 없으면 `won`. 마지막 적을 먼저 맞히면 방어선에 있어도 승리. 종료 후 시간·이동·발사·점수 모두 동결. |
| REQ-07 | 필수 | `won`/`lost`에서만 R 또는 재시작 버튼으로 `playing`의 새 판. 위치·적·탄환·점수·방향·키·시간·발사 대기시간·탄환 번호 초기화. `playing`의 Enter/R, 키 반복에 의한 시작·재시작은 무시. |
| REQ-08 | 필수 | 상태·점수·남은 적·시작/재시작 버튼을 접근 가능한 DOM으로 제공. 상대 에셋, 외부 런타임 의존성 없음, 배포 결과는 `dist`만. 키 설명, 포커스 표시, 반응형 화면 제공. |

## 입력과 상태 전환

- `title` → `playing`: Enter 또는 시작 버튼.
- `playing` → `won`/`lost`: REQ-06 판정만 허용.
- `won`/`lost` → `playing`: R 또는 재시작 버튼만 허용.
- blur와 상태 전환에서 모든 키를 비운다. 시작·재시작·포커스 복귀 때 프레임 시각을 초기화한다.
- 키를 계속 누른 채 상태가 바뀌어도 자동 반복으로 새 판 입력이 되살아나지 않는다. 새로 눌러야 한다.
- 버튼 Enter/Space는 브라우저의 기본 버튼 활성화를 사용하고 전역 단축키와 중복 처리하지 않는다.
- blur는 일시정지가 아니다. 보이는 화면에서는 입력만 해제하고 게임이 진행된다. 숨겨진 탭에서 놓친 시간을 나중에 따라잡지 않는다.

## 제외와 미결정

목숨·적 탄환·사운드·모바일 조작·온라인 순위·여러 웨이브·일시정지는 제외한다.
최초 구현을 막는 미결정 수치는 없다. 실제 인간 플레이·공개 배포 검증은 별도다.
