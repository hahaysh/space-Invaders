# CHG-01 — P 키 일시정지·재개

## 배경·기준·허용 범위

잠시 자리를 비웠다가 같은 게임 상황으로 돌아올 수 있도록 일시정지와 재개를 추가한다.
비교 기준은 최초 샘플의 **로컬 체크포인트 `0162756`**이다. 최초 배포 SHA나 공개 URL이 아니다.
사용자는 2026-09-13 개선 샘플의 문서 → 구현 → 검증을 자동 산출물 리허설로 허용했다.
실제 참가자별 승인 대화·app UI 조작·원격 동기화·중간 커밋을 그대로 수행한 것으로 기록하지 않는다.
작업 범위는 `src/game-samples/improved-release`뿐이며 최초 샘플을 수정하지 않는다.

## 제외

blur 자동 일시정지, 재개 버튼, 목숨, 적 탄환, 사운드, 모바일 조작, 여러 웨이브, 새 게임 규칙은 제외한다.
커밋·푸시·PR·병합·Pages 설정·원격 배포는 허용 범위가 아니다.

## 상태·후속 기록

작성 시점: 요청·영향 분석을 기록했으며 아직 개선 구현·테스트는 미수행이다.
이번 요청은 자동 리허설 허용이며 인간의 기능 확인·원격 배포 완료 승인이 아니다.
최종 실제 완료 범위는 로컬 검증 후 이 절과 `TEST_RESULTS.md`에 기록한다.

최종 기록(2026-09-13): CHG-01-AC1~7의 자동 검사와 REQ-01~08 회귀를 통과했다.
Node 42개, Chromium 13개, 빌드 및 `/improved-release/` 상대 에셋·P 동작 검사를 확인했다.
이는 **로컬 자동 검증 완료**다. 인간 플레이·app UI·실제 OS 포커스·공개 재배포는 미확인이다.
커밋은 상위 작업자의 검토 후 처리하며 이 작업에서는 만들지 않았다.
