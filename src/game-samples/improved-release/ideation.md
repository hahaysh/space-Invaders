# 아이디어: 궤도 수호대

## 문제와 대상

키보드 게임을 처음 접하는 데스크톱 사용자에게 짧고 명료한 한 판을 제공한다.
문서의 규칙을 직접 움직이는 화면과 테스트로 연결하는 것이 실습 목표다.

## 후보 비교와 선택

| 후보 | 경험 | 장점 | 비용 |
|---|---|---|---|
| 어두운 우주·민트빛 기체 | 하강하는 편대를 막는 집중감 | 직접 그린 도형만으로 명확한 구분 | 낮음 |
| 종이 정원·씨앗 발사 | 밝고 친근한 분위기 | 색상 변형이 쉬움 | 우주 방어 규칙 설명과 거리 |
| 해저 관측·잠수정 | 깊이감 있는 탐사 | 시각적 개성 | 배경 장식으로 범위 확대 위험 |

리허설에서는 첫 후보를 선택한다. 제목은 **궤도 수호대**이며 짙은 남색, 민트색 기체, 호박색 적으로 구성한다.
참가자의 실제 후보 선택 대화를 재현한 기록은 아니다.

## 한 판의 흐름과 범위

대기 → 시작 → 좌우 이동·발사 → 적 편대 제거 또는 방어선 도달 → 승패 확인 → 재시작.
시작과 결과는 버튼·키보드로 조작하고 상태와 점수는 화면의 글자로도 읽는다.
원본 이미지·글꼴·음원 없이 자체 도형을 그린다.

목숨, 적 탄환, 사운드, 로그인, 순위, 모바일 조작, 여러 웨이브는 제외한다.
일시정지·재개는 후속 CHG-01 후보이며 최초 릴리스에 넣지 않는다.

## PRD로 넘기는 결정

속도, 적 간격·시작 위치·하강량, 사각형 충돌 경계, 발사 간격,
동시 입력·종료 우선순위를 `PRD.md`에서 수치와 조건으로 확정한다.
이 문서는 구현이나 테스트 성공을 주장하지 않는다.
