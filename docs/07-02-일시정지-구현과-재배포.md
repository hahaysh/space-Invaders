# 07-02. 일시정지 구현과 재배포

[이전](07-01-일시정지-요청과-설계.md) · [전체 목차](00-전체-실습-안내.md) · [다음: 난이도 선택 설계](08-01-난이도-선택-설계.md)

## 이번 실습

승인한 일시정지를 작은 변경으로 구현하고 같은 `game-check` Skill을 다시 사용합니다.
기능 PR과 실제 재배포 확인까지 완료하면 기본 16개 실습이 끝납니다.
선택 확장은 이 완료된 main에서 따로 시작합니다.

## 시작 전

- 일시정지 이슈의 같은 기능 세션에 승인 문서가 있습니다.
- 계획 표와 TEST_PLAN에 새 조건이 반영됐습니다.
- App **Plan**에서 변경 파일과 검사 범위를 마지막으로 확인합니다.

**모드: Plan**

```text
승인된 일시정지 문서와 현재 코드를 기준으로 최소 구현 순서를 확인해 줘.
기존 모델/UI 구조를 유지하고 새 상태·입력·시간 처리와 표시만 바꿔 줘.
Skill로 확인할 새 동작과 기존 게임 회귀 범위를 짧게 보여 주고 멈춰 줘.
```

## 승인 후 구현·검증

App을 **Interactive**로 전환합니다.

**모드: Interactive**

```text
일시정지 구현을 승인해. 문서의 P/paused 규칙을 코드와 UI에 반영해 줘.
README에 P 조작을 추가하고 실제 배포 주소는 보존해 줘.
game-check Skill을 사용해 일시정지와 전체 필수 기능 회귀·빌드를 검증해 줘.
정지 동안 값/시간/cooldown 유지, 반복 P 무시, 재개 후 정상 속도를 검사해 줘.
Node의 제어 시간 검사와 Playwright의 실제 P 입력을 구분해 줘.
Skill 미인식이면 대체 읽기 검증이라고 표시하고 실제 결과만 기록해 줘.
계획 표·TEST_RESULTS를 갱신하고 diff를 보여 준 뒤 원격 제출 전에 멈춰 줘.
```

실제 화면에서 진행 중 P → 잠시 기다림 → P를 눌러 봅니다.
정지 표시뿐 아니라 위치·점수·탄환이 유지되는지 확인합니다.
키를 길게 눌러 여러 번 토글되지 않는지, 재개 후 이동이 튀지 않는지도 봅니다.
화면 확인만으로 cooldown 경계를 증명하지 말고 해당 자동 검사 근거를 함께 읽습니다.

## PR·재배포

로컬 결과와 diff가 맞으면 아래 범위로 승인합니다.

**모드: Interactive**

```text
검토한 변경을 커밋·푸시하고 main 대상 일시정지 PR을 만들어 줘.
실제 검사와 수용 기준을 설명하고 코드 수용 완료한 일시정지 이슈를 Fixes로 연결해 줘.
PR 검사 결과를 알려 주고 사람의 병합 승인 전에는 멈춰 줘.
```

App PR 화면이나 GitHub 웹에서 검사·diff를 검토하고 사람이 병합을 승인합니다.
main 배포와 필요한 환경 승인을 확인한 뒤 실제 공개 URL을 다시 엽니다.

**모드: Interactive**

```text
병합 커밋과 Actions 배포를 확인하고 실제 공개 URL에서 P 정지/재개와 기본 조작을 확인해 줘.
커밋·run 링크·URL·실제 확인 방식·미확인을 일시정지 이슈 댓글에 기록해 줘.
이미 코드 PR로 닫힌 이슈에도 공개 확인 결과를 남기고 실패하면 미완료를 명시해 줘.
```

재배포 후 문서 기록만을 위해 반복 PR을 만들지 않습니다.
로컬 검증과 기능 설명은 기능 PR에, 공개 확인은 원격 이슈에 보존합니다.
[06-03에서 기록 PR은 한 번 완료](06-03-PR과-첫-배포.md)했으므로 여기서는 추가 기록 PR을 만들지 않습니다.

## 눈으로 확인

- [ ] 실제 P 입력과 시간/cooldown 경계 검사가 통과했습니다.
- [ ] 기존 시작·이동·발사·승패·재시작이 유지됩니다.
- [ ] README 조작과 실제 결과가 기능 PR에 포함됐습니다.
- [ ] 사람의 PR/환경 승인 후 공개 URL에서 개선을 확인했습니다.
- [ ] 원격 증거와 남은 로컬 변경이 구분됐습니다.

## 실패했을 때만 복구

**모드: Interactive**

```text
실패한 정지/재개 또는 기존 동작을 실제 재현해 최소 수정해 줘.
관련 회귀와 공개 확인까지 다시 수행하고 기존 통과 주장을 근거에 맞게 정정해 줘.
병합 후 수정이면 최신 main의 새 수정 PR을 사용해 줘.
```
