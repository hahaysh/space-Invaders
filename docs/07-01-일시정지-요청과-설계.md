# 07-01. 일시정지 요청과 설계

[이전](06-03-PR과-첫-배포.md) · [전체 목차](00-전체-실습-안내.md) · [다음: 일시정지 구현과 재배포](07-02-일시정지-구현과-재배포.md)

## 이번 실습

“잠깐 멈췄다가 이어 하고 싶다”는 사용자 요청을 제품 변경으로 바꿉니다.
첫 배포를 고치던 오래된 브랜치가 아니라 **최신 main의 새 기능 세션**에서 시작합니다.
기존 게임을 다시 생성하지 않고 달라질 상태와 검증만 설계합니다.

## 시작 전

- 첫 배포의 실제 공개 URL과 원격 이슈 증거가 있습니다.
- 직전 PR이 병합됐고 main에 필요한 게임·Skill·문서가 있습니다.
- App **Interactive**에서 이슈 생성을 요청합니다.

**모드: Interactive**

```text
최신 main과 첫 배포 결과를 확인한 뒤 '우주 방어 일시정지' 이슈를 만들어 줘.
목표는 P로 진행 중 게임을 멈추고 같은 상태에서 재개하는 것이야.
범위·완료 점검·기존 PRD/TRD와 배포 결과 링크를 짧게 넣어 줘.
키 반복 무시, 시간/입력 처리, 기존 규칙 보존, 회귀 검사·재배포를 포함해 줘.
코드 수정은 아직 하지 마.
```

**My work → 일시정지 이슈 → New session**으로 최신 main 기반 세션을 엽니다.
예시 브랜치는 `feature-pause`입니다. 선택 base와 현재 브랜치를 확인합니다.
App 설정의 신뢰 요청과 Skill 사용 가능 여부도 새 세션에서 확인합니다.
이슈 링크는 이전 작업의 결과를 이어 주며 이전 세션의 미커밋 파일을 대신하지 않습니다.

## App Plan: 변경 설계

**모드: Plan**

```text
일시정지 이슈·AGENTS·PRD·TRD와 현재 코드를 읽어 줘.
playing/paused에서만 P가 토글되고 repeat 이벤트는 무시하도록 설계해 줘.
paused에서는 적·탄환·점수·게임 시간·발사 cooldown이 모두 멈춰야 해.
전환 시 입력을 비우고 재개 시 시계를 재설정해 이동이나 연속 발사가 몰리지 않게 해.
루프는 하나를 유지하고 자동 blur 일시정지나 새 단축키는 추가하지 마.
기존 title/won/lost 조작과 모든 게임 규칙은 보존해 줘.
PRD/TRD/TEST_PLAN의 필요한 수정과 계획 표의 변경 작업만 제안해 줘.
이번에는 코드 구현 없이 문서 변경안을 검토할 수 있게 멈춰 줘.
```

정지는 화면 덮개만 보이는 상태가 아닙니다.
재개할 때 정지한 시간만큼 적이 갑자기 내려오거나 발사가 몰리면 잘못된 것입니다.
브라우저 포커스 이탈 시 기존 입력 정리는 유지하지만 자동 정지는 별도 기능이므로 넣지 않습니다.

## 승인 후 문서 갱신

App을 **Interactive**로 전환합니다.

**모드: Interactive**

```text
변경 설계를 승인해. PRD·TRD·TEST_PLAN의 필요한 부분과 계획 표를 갱신해 줘.
이슈에 승인한 범위와 검증 기준을 짧게 남겨 줘.
README의 실제 배포 URL을 보존하고 직전 공개 근거는 확인된 이슈 링크를 참조해 줘.
ideation·AGENTS는 역할이나 규칙이 바뀌지 않으면 그대로 두고 코드는 아직 바꾸지 마.
```

새 변경 보고서 여러 개를 만드는 대신 이슈와 기존 문서에 연결합니다.
기본값 수치표는 그대로 두고 새 상태와 조작 규칙만 추가합니다.

## 눈으로 확인

- [ ] 새 이슈·기능 세션이 최신 main에서 출발했습니다.
- [ ] P의 상태별 동작과 반복 무시가 명확합니다.
- [ ] 정지 중 모든 시간과 cooldown이 동결됩니다.
- [ ] 입력 정리·시계 재설정·한 루프·자동 blur 정지 제외가 반영됐습니다.
- [ ] 기존 규칙을 보존하는 문서 변경만 승인했습니다.

## 필요할 때만 보완

```text
일시정지 설계에서 기존 규칙과 충돌하는 부분만 고쳐 줘.
정지/재개 전후 무엇이 같아야 하는지 관찰 가능한 완료 조건으로 보완해 줘.
```
