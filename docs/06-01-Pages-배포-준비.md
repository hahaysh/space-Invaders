# 06-01. Pages 배포 준비

[이전](05-02-결함-수정과-회귀-검증.md) · [전체 목차](00-전체-실습-안내.md) · [다음: 배포 워크플로](06-02-배포-워크플로.md)

## 이번 실습

게임을 공개하기 전에 공개 범위와 Pages 배포 권한을 확인합니다.
워크플로 성공과 공개 게임의 정상 동작은 다르므로 각각 확인할 준비를 합니다.
저장소 설정의 사람 승인이나 환경 보호를 우회하지 않습니다.

## 시작 전

- 같은 검증·배포 이슈 세션이며 로컬 필수 검증을 마쳤습니다.
- 참가자 저장소가 Public이고 설정을 확인할 권한이 있습니다.
- App **Plan**에서 공개할 파일과 필요한 설정을 점검합니다.

## 공개 준비 계획

```text
현재 저장소·브랜치·검증 결과를 확인하고 Pages 준비 상태를 점검해 줘.
공개하면 안 되는 비밀·개인 파일·불필요한 산출물이 추적되는지 확인해 줘.
Vite base './'와 빌드 dist만 배포하는 경로를 점검해 줘.
GitHub Pages source는 GitHub Actions, github-pages 환경은 main만 배포 허용으로 해.
현재 보호 규칙을 유지하며 필요한 최소 설정 변경을 제안해 줘.
App/API가 확인한 사실과 사람이 GitHub UI에서 확인/승인할 항목을 나눠 줘.
워크플로 작성·설정 변경·배포는 아직 실행하지 마.
```

Public 저장소의 소스는 공개됩니다. `dist`만 배포해도 저장소의 비밀이 숨겨지는 것은 아닙니다.
실제 비밀이 발견되면 배포를 멈추고 노출 범위·폐기/교체를 따로 처리합니다.
자격 증명을 문서·설정·로그에 넣어 해결하지 않습니다.

## 승인 후 GitHub 설정

App을 **Interactive**로 바꾸고 검토한 준비만 요청합니다.

```text
확인한 최소 준비를 승인해. 로컬 설정 보완과 필요한 설정 확인을 도와줘.
허용된 도구로 가능한 부분만 실행하고 사람의 UI 조작이 필요한 위치를 알려 줘.
보호 규칙·환경 승인을 제거하거나 비밀을 저장하지 말고 실제 결과를 보고해 줘.
```

GitHub 웹의 **Settings → Pages → Build and deployment → Source**에서
**GitHub Actions**를 선택하거나 이미 선택됐는지 확인합니다.
**Settings → Environments → github-pages**에서 배포 브랜치 정책을 확인합니다.
환경이 없으면 만들고, **Selected branches and tags**에서 branch `main`만 허용합니다.
태그와 다른 브랜치는 허용하지 않습니다. “보호된 브랜치만”이 모든 환경에서 main만 뜻하지는 않습니다.
기존 reviewer·대기 같은 보호 규칙은 유지합니다.

도구/API가 설정했다면 응답과 UI 결과를 구분해 기록합니다.
권한이 없으면 저장소 소유자의 설정 승인을 기다립니다.
이전 demo의 직접 main 병합 예외를 참가자 경로로 따라 하지 않습니다.

## 배포 대상 확인

예상 Pages 주소는 저장소 이름을 포함할 수 있지만 아직 실제 URL로 확정하지 않습니다.
Vite `base: './'`로 생성 자산이 저장소 하위 경로에서 로드되는지 확인합니다.
빌드 아티팩트는 게임 결과인 `dist`뿐이며 소스·테스트 결과·node_modules 전체를 올리지 않습니다.
GitHub Pages는 정적 호스팅이므로 서버 API나 외부 게임 자산에 기대지 않습니다.

## 눈으로 확인

- [ ] 대상 Public 저장소와 공개할 추적 파일을 검토했습니다.
- [ ] Pages source가 GitHub Actions입니다.
- [ ] `github-pages` 환경은 main 브랜치만 허용하고 기존 보호가 유지됩니다.
- [ ] `dist` 전용 빌드와 하위 경로 로딩 검증이 준비됐습니다.
- [ ] API 확인·사람 UI 확인·미확인 사항이 구분됐습니다.

## 필요할 때만 보완

```text
Pages 또는 환경 설정에서 막힌 항목의 실제 응답과 권한을 확인해 줘.
보호를 완화하지 말고 소유자가 승인해야 할 최소 작업만 안내해 줘.
```

## 완료

공개 범위와 배포 환경을 확인했습니다.
설정만 끝난 상태를 배포 성공으로 기록하지 않고 다음 단계로 이동합니다.
