# 08-01. 난이도 선택 설계

[이전](07-02-일시정지-구현과-재배포.md) · [전체 목차](00-전체-실습-안내.md) · [다음: 난이도 구현과 재배포](08-02-난이도-구현과-재배포.md)

## 이번 실습

선택 과정에서는 게임 시작 전에 적 속도를 고를 수 있게 합니다.
선택 중인 값과 현재 판에 적용된 값을 구분하는 것이 핵심입니다.
이전 데모의 예외를 따르지 않고 **새 이슈·새 기능 브랜치·PR**로 진행합니다.

## 시작 전

- 일시정지가 병합·재배포된 최신 main이 있습니다.
- 공개 확인 증거와 필요한 문서가 원격에 보존됐습니다.
- App **Interactive**에서 이슈를 먼저 만듭니다.

```text
최신 main의 일시정지 완료를 확인하고 '우주 방어 난이도 선택' 이슈를 만들어 줘.
목표·범위·완료 점검·관련 문서 링크를 짧게 적어 줘.
쉬움/보통/어려움 적 속도 선택과 기존 게임 회귀·재배포를 포함해 줘.
아직 문서나 코드를 수정하지 마.
```

**My work → 난이도 이슈 → New session**으로 최신 main을 선택합니다.
예시 브랜치는 **`feature-difficulty`**이며 App 접두사는 허용합니다.
선택 base·현재 브랜치와 일시정지 코드·Skill을 확인한 뒤 **Plan**으로 전환합니다.

## 변경 기준

| 항목 | 결정 |
|---|---|
| 속도 | 쉬움 32 / 보통 64 / 어려움 96 px/s |
| 초기값 | 페이지 새로고침 시 보통, 저장하지 않음 |
| 선택 가능 | title·won·lost에서만 |
| 선택 잠금 | playing·paused에서는 변경 불가 |
| 적용 | 선택 값(pending)을 시작/재시작 때 현재 값(current)으로 적용 |
| 잘못된 값 | 명시적인 오류로 알림, 조용히 보통으로 대체하지 않음 |
| 표시 분리 | 기존 점수 옆에 '이번 게임 난이도' 카드(current), 별도 설정 행의 '다음 게임 난이도' select(pending) |

```text
난이도 이슈·PRD·TRD·현재 코드를 읽고 위 기준의 변경 설계를 제안해 줘.
pending 선택과 current 판 설정을 구분하고 title/won/lost에서만 선택하게 해 줘.
playing/paused에서는 UI와 모델 모두 설정 변경을 막아 줘.
기본 HTML select의 화살표/Space/Enter 조작을 게임 단축키가 빼앗지 않게 해 줘.
시작/재시작 때 적용, 새로고침 보통, 잘못된 값은 명시적 오류로 처리해 줘.
점수와 같은 크기의 current 난이도 카드를 추가하고 pending select는 카드 밖에 분리해 줘.
적 수·점수·하강량·승패·P 동작은 유지하고 자동 레벨 상승은 넣지 마.
문서·계획 표·검사에 필요한 변경만 제안하고 구현 전에 멈춰 줘.
```

select에 포커스가 있을 때 Enter는 선택 조작이어야 합니다.
사용자가 시작 버튼으로 이동하거나 선택을 마친 뒤 게임을 시작하도록 설계합니다.
속도만 달라지며 총점·적 탄환 등 다른 규칙을 새로 만들지 않습니다.
제목 화면의 current 카드는 초기 보통이며 선택만 바꾸면 그대로입니다. 시작할 때 적용된 값으로 바뀝니다.
won/lost에서도 다음 선택을 바꾸는 것만으로 종료된 판의 카드 값을 덮어쓰지 않습니다.

## 승인 후 문서 작성

App을 **Interactive**로 전환합니다.

```text
난이도 설계를 승인해. PRD·TRD·TEST_PLAN과 계획 표의 필요한 부분만 수정해 줘.
이슈에 승인한 기준을 남기고 기본 수치표와 겹치는 복사본은 만들지 마.
아직 코드를 바꾸지 말고 문서 diff를 보여 줘.
```

## 눈으로 확인

- [ ] 최신 main 기반 새 난이도 이슈·세션·기능 브랜치입니다.
- [ ] 세 속도와 초기 보통이 명확하며 다른 규칙은 그대로입니다.
- [ ] pending/current와 상태별 선택 가능 여부가 분리됐습니다.
- [ ] 같은 스타일의 두 카드와 별도 select가 있으며 선택만 바꿔서는 current 표시가 변하지 않습니다.
- [ ] native select의 키보드 동작과 잘못된 값 오류가 설계됐습니다.
- [ ] 기존 일시정지·게임 회귀를 포함한 문서 변경만 승인됐습니다.

## 필요할 때만 보완

```text
선택 값과 현재 판 설정이 섞인 부분만 바로잡아 줘.
select 키보드 조작과 잠금 상태를 실제 확인 가능한 조건으로 보완해 줘.
```
